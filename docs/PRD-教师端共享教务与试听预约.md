# 教师端共享教务、试听预约、周排课拖动与全站界面改版

本文件是本项目这次改版的唯一需求依据。此前的 Codex `PLAN.md` 均为历史草稿；后续调整直接修改本文件。

## 目标和用户

系统只服务管理员和教师办公，不建设学生端。管理员创建、编辑、停用教师账号并管理全部教务数据。教师共享查看学生、教师基本信息、课程、周排课、日历、试听预约和点名记录；列表提供「全部／我的」筛选。服务端必须核对写入权限，前端明确呈现只读状态。

| 对象 | 教师 | 管理员 |
|---|---|---|
| 教师账号 | 查看基本信息 | 创建、编辑、停用 |
| 正式课程、周排课、调课 | 创建自己的，仅修改或归档自己的 | 管理全部 |
| 试听预约 | 查看全部，创建、修改、取消自己的 | 管理全部 |
| 学生 | 录入、查看全部；修改自己或管理员录入的；仅归档自己录入的 | 管理全部 |
| 点名 | 查看全部；仅记录和撤销自己的 | 管理全部 |

管理员录入的学生仅管理员能归档。学生增加独立的「待报名／已报名」阶段；试听学生先进入共享学生库，阶段为待报名，不参与正式课时不足提醒。保留原有在读、退学等状态。学生详情显示录入人。业务删除使用归档或软删除，不抹去点名、课时和课程历史。

## 正式课、调课和时间冲突

学生可以参加不同教师的正式课。同一教师或同一学生的课程时间不得重叠；不同教师且没有共同学生的课程可同时进行。创建、改时间、改名单、调课、交接由服务端检查冲突；已有历史冲突仅标记供人工处理。

周排课一次加载并展示连续两周，周导航每次前进或后退两周。PC 与 iPad 使用同一张十四日时间网格，可把课程或整天课程直接移至第二周；iPad 触屏长按后拖动；手机两周上下排列，不支持拖动，用日期表单调整。起始时间吸附到 30 分钟，保留时长，目标不能是过去、网格外或冲突时段。单击课程卡片打开详情；鼠标只能从卡片右上角的可见手柄开始拖动，移动超过 10 像素进入拖动，无需等待长按，卡片正文的鼠标移动不调课；触屏长按后拖动，网格空白处仍可滚动页面。无权编辑的课程不可拖动。第二周新建的固定课程从第二周开始每周生效，不能提前出现在第一周。

每次放下先显示新日期和时间，再选择「仅这一次」或「从这次起每周」并确认。前者创建单次调课记录，其他周照旧；后者建立从所选课次生效的新固定课表版本，过去的课次保留原样。表单编辑采用相同范围和校验。已过去的课次只读，已点名和课时历史保留。周视图由固定课表版本和单次调课合成实际课次，单次调课按原课程和原日期定位，避免在原位置重复出现。点名、试听预约关联实际课次。保存失败恢复原位置。

整天调课保持每节课原开始时间与时长；任一课程冲突或不允许调课时，整批事务回滚。临时把本周六移到下周二后，本周六为空、下周二上课，而下周六及以后各周六照常上课。若选择永久更改，本周六移到下周二后，从下周起每周二上课，原周六不再上课；跨周永久调课的固定课表从目标所在的下一周生效。独立试听预约不自动移动。

## 临时代课（2026-10-09 补充）

原授课老师和管理员可为自己的具体课次安排其他在用老师代课，可填写原因。只对这一节生效，后续周次自动恢复原老师；课程归属和正式学生名单不变。代课老师仅获得该课次的点名权限，不能据此修改、调课或交接整门课程。学生照常扣课时，教师点名及耗课统计归实际授课老师；管理员代点名也按实际老师统计，并保存老师 ID 与姓名快照以免后续变化改写统计。

代课老师此时段若有正式课或试听重叠，列出冲突安排并询问是否仍安排。确认前不保存；明确确认后允许保存，这仅是安排临时代课时的冲突例外。服务端再次核对冲突，若确认期间出现新冲突或原冲突时段变化，重新提示。其他课程创建、调课、整天移动继续按原冲突校验。

周排课详情提供安排、更换及取消本次代课，卡片标记代课并使用实际老师的区分色。取消或更换保留原记录和操作人。已开始或已点名的课次不能修改代课。已有有效随课试听预约须先取消或重新安排；不自动换预约老师。单次调课保留课次原日期标识，代课随该课次移动；改变或移除后续固定课表前须处理受影响的代课。教师停用前须处理未来代课。

导航补充：PC 和 iPad 直接显示同一组主导航及“更多”，不设“打开导航”按钮。700px 及以上保持一行，600–699px 窄窗口直接显示两行；手机继续只使用底部菜单。

## 一次性试听预约

每条预约是一名已录入学生、负责教师、具体日期时间及可选备注，状态为有效或取消。预约在正式课上时关联该日期的实际课次并沿用时间；一节课可有多名试听学生。无对应正式课可建独立试听时段。服务端检查教师和学生冲突；正式课学生不能作为该节的试听学生。已开始的时段不能补建预约，已开始的预约保留历史且不可修改或取消，判断精确到日期和开始时间。试听学生不加入正式名单，不点名、不扣课时、不纳入正式课统计。

新增「试听预约」导航和管理页，可按日期、教师、学生、状态查询，并创建、修改、取消、查看历史。正式课卡无需点击即可显示「试听预约 N 人」，详情分开展示正式和试听学生；独立预约显示为独立日程。日历混合展示两类日程，同时上课的不同教师并列区分。

调课、改教师、交接或归档若影响未来有效试听预约，服务端阻止本次操作并列出预约。操作者须先逐条取消或重新安排；系统不自动移动或取消。历史保留当时的课程、教师、学生及时间信息。

## 数据、接口和验收

增加预约、报名阶段、归档、固定课表生效版本和单次调课数据。旧学生按现有迁移规则归管理员录入，旧课程按原时间继续每周显示。备份、恢复和测试数据清理覆盖新增数据。读接口提供共享视图，写接口按归属和业务规则授权；冲突和预约检查在服务端事务中完成。撤销点名保留原记录与冲正流水，余额正确。

实施先完成现状清单和测试基线，然后迁移与权限、课次计算与调课、预约、统一组件和全站页面，最后验收。验收涵盖：教师不能改别人数据；跨教师选课无误；冲突受阻；PC 两周跨周拖动及两种生效范围；iPad 同周 30 分钟拖动；手机编辑；整天调课冲突整批回滚；历史拖动受阻；试听标记和详情；试听不点名扣课时；未来预约阻止受影响调课；软删除与撤销保留历史；备份恢复；PC、iPad、手机关键流程及现有功能回归。
